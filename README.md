# E-Commerce Sales Forecasting

**Author:** Shohidul Islam Remon 

## Project Overview
This repository contains a time-series forecasting analysis for an e-commerce company. The goal of this project is to analyze 730 days of historical daily sales data and build a predictive model to forecast Q1 2024 revenue, aiding in inventory and marketing budget planning.

## Files Included
* `forecast_analysis.ipynb`: The main Jupyter Notebook containing the Python code, data exploration, and Prophet model training.
* `sales_data.csv`: The historical dataset (2022-2023).
* `q1_2024_forecast.csv`: The output dataset containing the 90-day predictive forecast.
* `ANSWERS.txt`: Business insights and executive summary.
* `sales_exploration.png` & `day_of_week.png`: Data visualizations.

## Key Insights
* **Seasonality:** Strong weekend purchasing patterns, with Friday-Sunday generating ~50% more revenue than weekdays.
* **Forecast:** Projected Q1 2024 revenue is ~$214,410, requiring an inventory stock of roughly 11,500 units to prevent weekend stockouts.
